llmwiki does not ship a template publisher, a tap client, or remote profile
installation. The `template publish`, `template tap`, `template init`,
`template search`, `template status`, `template update`, `template verify`, and
`profile validate` commands this guide documented no longer exist: there is no
CLI, no template registry, and no remote profile package format in the product.

The walkthrough this page carried, and the signing protocol appendix behind it,
described signing, hosting, and installing remote profile packages for a profile
system llmwiki no longer has. A project's profile is a constant - `concepts`
under `wiki/concepts` and `queries` under `wiki/queries` - so nothing remains for
a remote package to declare. The walkthrough and the appendix were removed
rather than rewritten, because no library surface replaces them.

To move compiled knowledge to another tool or project, export an OKF bundle
instead:

- [Open Knowledge Format](/guides/open-knowledge-format) for the bundle round trip.
- [SDK guide](/guides/sdk) for `wiki.exportOkf()` and `wiki.importOkf()`.
- [MCP agent integration](/guides/mcp-agent-integration) for the `export_okf` tool.
