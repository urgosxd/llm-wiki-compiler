Newsroom is not a shipped template, and the Configurable Lifecycle Profile
machinery it demonstrated is gone. llmwiki has no template registry, no
declarable entity types or lifecycle states, no workflow engine, and no review
approval command, so this guide's walkthrough - `template init newsroom`,
`profile validate`, `profile show`, `workflow start`, `workflow status`,
`workflow submit`, `workflow advance`, `workflow gate approve`,
`workflow action show`, and `workflow action run` - taught commands and surfaces
the product does not have.

A project has one profile, the built-in default: `concepts` under
`wiki/concepts` and `queries` under `wiki/queries`. There are no `articles`,
`desks`, or `bylines` entity types, no `filed-under` relation type, and no
`story-pipeline` workflow, so the editorial model this page described cannot be
expressed in the current product. The walkthrough was removed rather than
rewritten: no library surface survives to name in its place.

What remains is the pipeline itself - ingest, compile, query, lint, and export -
available in-process through the SDK and over the wire through MCP:

- [SDK guide](/guides/sdk) for `createWiki()` and its methods.
- [MCP agent integration](/guides/mcp-agent-integration) for the tool list.
- [Open Knowledge Format](/guides/open-knowledge-format) for bundle export and import.
