description: "A wiki has one built-in profile: concepts under wiki/concepts and queries under wiki/queries. No project file, flag or environment variable configures it."
---

A wiki has exactly one profile, the built-in `default`, and nothing configures
it. Page types live at fixed directories:

```text
wiki/concepts/
wiki/queries/
```

Entity types, relations, lifecycles, artifacts, workflows, connectors and content
tiers are not declarable. `.llmwiki/profile.json` is not read, and no flag or
environment variable stands in for it.

The library still exposes the reading half of that one profile:
`activeProfileDigest(root)` returns its content-address, and
`loadNonDefaultProfile(root)` always returns `undefined`, because there is no
non-default profile to load.
