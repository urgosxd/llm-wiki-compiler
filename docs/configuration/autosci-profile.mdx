AutoSci was a built-in profile template, and profile templates are not part of
this build. AutoSci cannot be inspected, installed or validated, and none of the
entity types, relations, lifecycles, workflows, artifact types or connector
bindings it declared exist in a project today.

A wiki has exactly one profile, the built-in default, described in
[Profiles](/configuration/profiles).
