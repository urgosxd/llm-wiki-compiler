Profile templates, local template files and signed remote taps are not part of
this build. There is no template installer, no template registry and no tap
trust store, so nothing this page used to document can be inspected, installed,
verified or updated.

A wiki has exactly one profile, the built-in default, described in
[Profiles](/configuration/profiles).
