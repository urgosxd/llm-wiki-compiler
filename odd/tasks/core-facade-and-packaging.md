## Specs

**S1.** "Make it an **honest facade**: whatever it re-exports should be a deliberate, named surface rather than an accident of which wiki sources its tsup happens to compile."

**S2.** "**`exports` → `dist`** for the published entries, with subpaths that actually resolve."

**S3.** "**`workspace:*` in the packed manifest.** The rule is already settled and guarded: `dependencies` must carry **no `workspace:`** (20 registry ranges today), while `devDependencies` legitimately do (four occurrences, and `test/affected-escalation-wiring.test.ts:171` deliberately requires one). **Do not "fix" the `devDependencies` ones** — a guard in `test/declared-dependencies-wiring.test.ts` pins the scope and a comment explains why. If your change creates a `workspace:` under `dependencies`, that guard goes red and it is right to."

**S4.** "No change to `DimensionsPort`/`resolve`/`MissingDimensionsPortError`/`requireDimensionsPort`." and "No boundary-rule narrowing to make a gate pass. If a gate goes red, the gate is telling you something."

**S5.** Light gates, run now: "`gates:static` · `tsc --noEmit` · `typecheck:tests` · `typecheck:kg` · `lint` (**zero headroom**: literal `566 baseline violations in 402 files across 429 rule/file entries`; **`lint:update` is forbidden**) · `fallow:ci` · `fallow:kg` · `build` · `test:pack` · `vitest run test/sdk test/artifact`." Note `package.json` has **no** `test:artifact` script — do not cite one.

**S6.** Phasing, non-negotiable: "**Do:** implementation, `gates:static`, `tsc --noEmit`, `build`, `test:pack`, and targeted `vitest run test/sdk test/artifact`." / "**Do not:** run `pnpm test`, start Docker, or provision a database. Two full suites at once have already killed agents on this project, and a false red caused by memory pressure wastes more than it buys."

**S7.** "**The installed tarball pair is not installable alone**: `npm i <root tarball>` fails `ETARGET` on `@atomicstrata/llmwiki-core@1.4.0-dev…`, so both tarballs must be packed and installed. That is recorded as a known requirement, not a defect to fix silently — if S6 can make the root tarball self-sufficient, say what that costs; if not, record it."

**S8.** "Note `packages/wiki/package.json` has 22 subpaths and **no `"."`**, so `import.meta.resolve("@repo/wiki")` is `ERR_PACKAGE_PATH_NOT_EXPORTED` — decide whether the facade needs that and say so; do not add a `"."` export to `@repo/wiki` casually, because it changes what a private package exposes."

**S9.** "`odd/tasks/published-entry-port.md` records why moving the root entry buys **nothing** for the SDK path. Read it before proposing any entry move — the question is settled and re-opening it wastes a slice."

**S10.** Hard prohibitions, as decisions: no history rewriting (no `git reset`, `git restore --staged`, `--amend`); no hook bypass of any kind; no `cp -a` of this worktree (`.git` is a pointer file, so a copy is a second handle on the same shared gitdir); no push; no `--no-verify`; no `HUSKY=0`. `odd/tasks/**` append-only except the tracker line.

**S11.** Why the hook-bypass prohibition can only be conducted, never gated: a hook cannot observe its own bypass and no static check in the repository can see *how* a command was invoked, so **disclosure is the entire enforcement mechanism**. That is why "the effect was nil" is not the reason a disclosure is unnecessary — it is the reason the disclosure is sufficient. Disclosed, not pardoned: `git status` runs no hooks and nothing was bypassed in the one recorded incident; the objection is to the form, and the form is what the real bypass looked like when it happened.

**S12.** Recorded-but-not-ours, must not be widened: `writeStateFor` with no production caller, `core-types.ts` returning `Promise<unknown>`, the `listSources()` row-path gap, the spurious `deleted`+`new` pending pair, the `review` removal (another slice owns it), and the `/health` origin-gate asymmetry.
